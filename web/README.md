# JobPilot — MVP

Лендинг, четырёхшаговый онбординг и рабочий кабинет поиска вакансий на русском языке. Фирменный знак — белый радар на красном фоне.

## Что работает

- `/` — лендинг с переходами к продукту и онбордингу.
- `/onboarding` — цель поиска, условия, навыки и текст резюме; импорт `.txt`.
- `/app` — личный кабинет: живой поиск вакансий hh.ru, сохранение, сравнение навыков, AI-документы и трекер.
- `/app?demo=1` — отдельный демонстрационный режим; изменения в нём не сохраняются после перезагрузки.
- `/api/state` — хранение профиля, вакансий, откликов и документов в Supabase с привязкой к пользователю.
- `/api/jobs/search` и `/api/jobs/[id]` — серверная интеграция с HeadHunter API.
- `/api/ai` — защищённая серверная интеграция с OpenRouter для разбора вакансии, письма и адаптации резюме.

Для входа используется Supabase Auth: email/password, Google и GitHub. API проверяет подписанные claims на сервере; ID владельца никогда не принимается из тела запроса. RLS ограничивает каждую запись её владельцем. Сохранение использует версию записи и отклоняет конфликтующие изменения из другой вкладки.

## Границы MVP

Демо-вакансии доступны только в отдельном `/app?demo=1`. В обычном кабинете вакансии приходят из HeadHunter API и сохраняются в Supabase. OpenRouter создаёт AI-разбор, сопроводительное письмо и адаптированный текст резюме без выдумывания опыта. Отклик отправляет сам пользователь на hh.ru; JobPilot пока не получает доступ к аккаунту соискателя. PDF/DOCX вводятся копированием текста. Платежей нет.

## Разработка

Node.js 22.13+, pnpm (версия зафиксирована в `package.json`).

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

Сайт работает на Next.js 16 и Vercel. Данные хранятся в таблице `public.workspaces` проекта Supabase; на таблице включён RLS. Переменные окружения перечислены в `.env.example`.

Чтобы включить живой поиск, зарегистрируйте приложение на `dev.hh.ru` и добавьте `HH_CLIENT_ID` и `HH_CLIENT_SECRET` в Vercel. Чтобы включить AI-функции, добавьте серверный `OPENROUTER_API_KEY` и выберите модель в `OPENROUTER_MODEL`. Эти секреты используются только в Route Handlers и не попадают в клиентский JavaScript.

Изменения схемы Supabase оформляются отдельными SQL-миграциями. Для всех таблиц в `public` обязателен RLS с проверкой `auth.uid() = user_id`.

## Проверка

```bash
pnpm exec tsc --noEmit
node --experimental-vm-modules scripts/check-product.mjs
```

Проверяются сопоставление навыков, валидация ссылок и зарплат, нормализация ответа hh.ru, очистка HTML, обязательный вход в API и отсутствие клиентских секретов. Изоляция владельцев дополнительно обеспечивается и проверяется политиками RLS в Supabase.

WebMCP при поддержке браузером предоставляет чтение соответствий и открытие разбора вакансии. Проверка в поддерживающем WebMCP браузерном контексте не выполнялась.
