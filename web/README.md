# JobPilot — веб-прототип

Лендинг, четырёхшаговый онбординг и личный кабинет на русском языке. Фирменный знак — белый радар на красном фоне.

## Что работает

- `/` — лендинг с переходами к продукту и онбордингу.
- `/onboarding` — цель поиска, условия, навыки и текст резюме; импорт `.txt`.
- `/app` — личный кабинет: свои вакансии, поиск и фильтры, сравнение навыков, документы и трекер.
- `/app?demo=1` — отдельный демонстрационный режим; изменения в нём не сохраняются после перезагрузки.
- `/api/state` — хранение профиля, вакансий, откликов и документов в D1 с привязкой к пользователю.

Для личного кабинета используется идентификация ChatGPT через Sites. API требует подтверждённую сервером идентичность; ID владельца никогда не принимается из тела запроса. Сохранение использует версию записи и отклоняет конфликтующие изменения из другой вкладки.

## Границы прототипа

Демо-вакансии вымышлены и явно подписаны. Реальные вакансии добавляются вручную. Автопоиск и отправка откликов на сторонние площадки не подключены. Разбор сравнивает явно указанные навыки, а документы создаются по шаблонам из фактов профиля; это не подключённая языковая модель. PDF/DOCX пока вводятся копированием текста. Платежей нет.

## Разработка

Node.js 22.13+, pnpm (версия зафиксирована в `package.json`).

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

Сайт использует Vinext, React, Cloudflare Worker и D1. База описана в `db/schema.ts`; миграции — в `drizzle/`. Объявление `DB` находится в `.openai/hosting.json`. Для локального входа заголовки пользователя не подделываются в продукте: без доверенной платформенной идентификации доступен демонстрационный режим. Не публикуйте Worker напрямую в обход доверенного диспетчера Sites.

Изменения схемы:

```bash
pnpm db:generate
```

Миграции применяются платформой при публикации. После применения не изменять существующие SQL-файлы, а создавать новые.

## Проверка

```bash
pnpm exec tsc --noEmit
node --experimental-vm-modules scripts/check-product.mjs
```

Проверяются сопоставление навыков, честность шаблонов, валидация ссылок и зарплат, обязательный вход в API, изоляция владельцев, конфликты версий и запрет cross-site записи. Тест API использует подмену привязки D1; он не заменяет проверку реального входа и работы в браузере. Схема и SQL дополнительно проверены в SQLite.

WebMCP при поддержке браузером предоставляет чтение соответствий и открытие разбора вакансии. Проверка в поддерживающем WebMCP браузерном контексте не выполнялась.
