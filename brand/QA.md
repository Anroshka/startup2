## Контраст

Расчёт по относительной яркости sRGB:

| Передний план / фон | Отношение |
| --- | --- |
| `#FFFFFF` / `#E52535` | 4,52:1 |
| `#202124` / `#FFFFFF` | 16,10:1 |
| `#68696D` / `#F6F5F3` | 5,03:1 |

Указанные пары превышают 4,5:1. Красный и белый находятся близко к порогу: не осветлять красный для кнопок с белым мелким текстом.

## Повторная проверка

```bash
python scripts/build_brand.py
python scripts/check_brand.py
```

Визуальная проверка PDF после изменений выполняется отдельно от структурной. Это проверка бренд-материалов, а не тестирование ещё не реализованного приложения.
