# Фирменный стиль JobPilot

Основной знак — белый радар на красном фоне. Иконка не содержит букв. Горизонтальный логотип соединяет знак и название JobPilot. Все основные материалы — на русском языке.

[Брендбук PDF](JobPilot_Brandbook.pdf) описывает позиционирование, аудиторию, геометрию, варианты знака, палитру, типографику, интерфейс, голос и носители.

## Использование

- Для README используйте `assets/jobpilot-banner.png`: файл непрозрачный, одинаково читается в светлой и тёмной теме GitHub.
- Логотип: `jobpilot-logo` на белой подложке и `jobpilot-logo-dark` на графитовой.
- Иконка: `jobpilot-icon` — 512 × 512, с прозрачностью за скруглёнными углами.
- Favicon: 16, 32 и 48 px. Версия 16 px упрощена для читаемости.
- `jobpilot-mark-black` и `jobpilot-mark-white` — монохромные варианты на контрастных подложках.
- Охранное поле: не менее 1/4 стороны иконки с каждой стороны. Для логотипа считать по высоте его знака.
- Минимум для основного знака — 24 px, для полного логотипа — 160 px по ширине. В 16 px использовать только специальную версию.
- Не менять пропорции, направление луча и геометрию. Не добавлять буквы, тени и градиенты.

SVG содержат векторные контуры без внешних шрифтов, скриптов, встроенных растровых изображений и сетевых ресурсов. Весь текст баннера также переведён в контуры. Для изменения текста используйте генератор; для редактирования формы SVG можно открыть в Figma, Inkscape или другом векторном редакторе.

## Сборка

Python 3.11 или новее. Выполнять из корня репозитория:

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS / Linux
# source .venv/bin/activate
python -m pip install -r scripts/requirements.txt
python scripts/build_brand.py
```

Генератор создаёт SVG, PNG, `brand/tokens.json` и `brand/JobPilot_Brandbook.pdf`. Шрифты поставляются локально; после установки Python-зависимостей сеть для сборки не нужна. PNG рендерятся из того же описания геометрии, что и SVG; PDF содержит встроенные шрифты с кириллицей.

## Цвет и доступность

| Сочетание | Контраст WCAG |
| --- | --- |
| Белый на красном `#E52535` | 4,52:1 |
| Графитовый на белом | 16,10:1 |
| Вторичный `#68696D` на светлом `#F6F5F3` | 5,03:1 |

Точные значения и проверка файлов приведены в [отчёте](QA.md). При изменении палитры пересчитайте контраст. Статусы должны иметь текстовые подписи; фокус клавиатуры должен быть видимым. Пример интерфейса в PDF иллюстрирует стиль и не означает, что приложение реализовано.

Палитра задана в sRGB. Для полиграфии подготовить преобразование по профилю типографии и утвердить цветопробу.

## Права

Шрифты DejaVu поставляются на условиях лицензии в [`fonts/LICENSE.txt`](../fonts/LICENSE.txt). Наличие бренд-материалов в публичном репозитории не означает выдачу лицензии на товарный знак. Юридическая проверка названия и знака перед коммерческим запуском не проводилась.
