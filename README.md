# JobPilot

**Career search, managed.**

JobPilot is a career-search product that turns job hunting into a managed pipeline. A user defines the target role, compensation, location and constraints once; JobPilot then helps find relevant openings, rank them by fit, prepare tailored applications from verified user data and track every opportunity from first contact to offer.

## Product

| Area | What JobPilot does |
| --- | --- |
| Discover | Finds roles that match the user's experience, preferences and constraints. |
| Match | Explains why a role fits and highlights missing or weak requirements. |
| Tailor | Adapts the presentation of a resume and cover note to a specific role without inventing experience. |
| Apply | Supports review-first applications and rule-based automation through allowed integrations. |
| Track | Keeps applications, replies, interviews and offers in one pipeline. |
| Prepare | Builds focused interview preparation from the vacancy and the user's actual background. |

## How it works

1. Import a resume or build a profile.
2. Set the target role, salary, location, work format and exclusions.
3. Review ranked vacancies with a clear match score.
4. Prepare a tailored application using only verified profile data.
5. Track progress and outcomes in one workspace.

## Product principles

- **Truth over optimization.** JobPilot never invents skills, experience, employers or results.
- **Control stays with the user.** Application rules, review mode and limits are explicit.
- **Relevant over numerous.** The goal is stronger matches, not the largest possible number of applications.
- **Traceable actions.** The user can see what changed, what was sent and why.
- **Platform-respectful.** Automation uses supported integrations and allowed workflows.

## MVP

The first version focuses on the core job-search loop: profile import, vacancy feed, match scoring, tailored application drafts, application tracking and a daily shortlist of strong opportunities.

## Business model

Freemium subscription. The free tier covers basic discovery and tracking; paid plans unlock higher usage limits, advanced tailoring, automation rules, analytics and interview preparation.
